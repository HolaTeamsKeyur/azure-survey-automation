# Five-minute demonstration script

## Preparation

- Use an Opportunity whose Contact email points to the presenter.
- Populate Region, Surveyor and Price List.
- Confirm the Price List has three recognisable products.
- Use an Order Confirmation whose Customer Contact email points to the presenter and which has installation start/finish.
- Keep Actionable Messages and Word attachment disabled for the first run.

## Survey demonstration

1. Open the Opportunity and show Survey Date/Time is empty and Customer Survey Automation has no response.
2. Run **Send Survey Demo**.
3. Refresh the Opportunity and show the proposed start/finish, Appointment ID, recipient, expiry and Sent status.
4. Open the email and explain that the link works in Outlook, Gmail and mobile browsers.
5. Open the secure link in a private browser.
6. Select products, Accept, add feedback and submit.
7. Refresh the Opportunity and show Accepted, selected product IDs, feedback and Responded On.
8. Show that no Quote or new custom table record was created.

## Installation demonstration

1. Open the Order Confirmation and show installation start/finish.
2. Run **Send Installation Confirmation Demo**.
3. Open the email and secure link.
4. Choose Request another time and enter a reason.
5. Refresh the Order and show the response/reason/timestamp.
6. Confirm the original installation start/finish did not change.
